## How Deployment Works

### Frontend (Static):
1. `npm run build` → `expo export --platform web`
2. Generates static HTML/CSS/JS in `dist/` directory
3. Vercel serves these files for all routes except `/api/*`

### Backend (Serverless Functions):
1. Functions in `api/` are automatically detected by Vercel
2. Each file becomes a serverless function
3. Routes configured in `vercel.json` rewrites

### API Routes:
- `POST /api/analyze` → `api/analyze.js`
- `POST /api/checkout/create` → `api/checkout/create.js`
- `POST /api/stripe/webhook` → `api/stripe/webhook.js`
- `POST /api/billing/portal` → `api/billing/portal.js`
- `GET /api/billing/invoices` → `api/billing/invoices.js`

## Deployment Steps

### Option 1: Automatic (Git Integration)
1. Push to your Git repository
2. Vercel automatically detects the push
3. Builds and deploys automatically

### Option 2: Manual (Vercel CLI)
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy (follow prompts)
vercel

# Deploy to production
vercel --prod
```

## Troubleshooting

### Build Fails:
- ✅ Check `npm run build` works locally first
- ✅ Verify all dependencies in `package.json`
- ✅ Check Vercel build logs for specific errors
- ✅ Ensure `dist/` directory is generated

### API Functions Return 500:
- ✅ Check environment variables are set in Vercel
- ✅ View function logs in Vercel dashboard
- ✅ Verify `server/lib/stripePlans.js` is accessible (included via `includeFiles`)

### Webhook Signature Verification Fails:
- ✅ Ensure `STRIPE_WEBHOOK_SECRET` matches Stripe dashboard
- ✅ Check webhook endpoint URL in Stripe matches Vercel URL
- ✅ Verify raw body is being passed correctly (Vercel handles this automatically)

## Important Notes

1. **Webhook Body Parsing**: Vercel automatically provides raw body for webhooks. The function has been updated to handle this correctly.

2. **File Paths**: All API functions use relative paths to `server/lib/stripePlans.js` which is included via `includeFiles` in `vercel.json`.

3. **Environment Variables**: Make sure to set ALL required variables in Vercel dashboard before deploying.

4. **Build Output**: The `dist/` directory is generated by Expo and contains all static assets. This is what Vercel serves.
